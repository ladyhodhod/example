Attention by hand

When a model reads the word “it”, it has to decide which earlier words help explain it. You’ll make that decision yourself, then check it with the same arithmetic a Transformer uses: queries, keys and values.

Step 1 · Where should “it” look?

Move the sliders to show how much attention “it” should pay to each highlighted word. The arcs grow as you give a word more attention. There are no wrong answers yet.

Your percentages always add up to 100%.

Step 2 · Score each word: query · key

Every word carries three small lists of numbers (vectors). Think of a library:

QueryWhat “it” is looking for. Like the question you type into the library search.
KeyWhat each word advertises about itself. Like the label on a book’s spine.
ValueThe information a word hands over if chosen. Like the book’s contents.

Our vectors have only two numbers, and each number has a meaning: [prey, predator] — how much a word is about the hunted animal, and how much about the hunter. Real models use hundreds of numbers, and nobody chooses what they mean — training does.

The query of “it” is . A word scores high when its key points the same way as the query. Multiply matching positions and add them up (the dot product):

[a, b] · [c, d] = a×c + b×d    e.g. [1, 3] · [2, 0.5] = 2 + 1.5 = 3.5

Step 3 · Turn scores into weights (softmax)

Scores can be any number. To get attention weights we need positive numbers that add up to 100%. Softmax does that in two moves: raise e ≈ 2.718 to the power of each score (bigger scores get much bigger), then divide by the total.

Step 4 · Collect the values

Attention decides how much to take from each word; the values are what gets taken. The new meaning of “it” is a mix of the values, weighted by attention.
